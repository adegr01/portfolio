Digit 100 Reflection Essay

For a project in my Digit 100 class, I had to code a website. We mainly focused on coding from scratch, but we also put our sites into Penn State's WordPress. I had a lot of fun with this project, especially the actual building of the site via HTML. One of the most challenging learning obstacles for me was CSS. I was a little confused, especially with how intricate everything was. With some help, I was able to figure out CSS. Another challenge for me was learning the git commands. Once I figured out how everything worked, it all came together smoothly. I preferred working with the HTML in Oxygen way more than I liked working with the Penn State WordPress. I found learning everything from scratch and building it that was, I found I retained the skill better and overall had more fun. The most important skill to me was knowing the git commands and making sure to push my edits to my GitHub repo. In conclusion, I had a lot of fun coding my website. I'd love to code another one in the future.
